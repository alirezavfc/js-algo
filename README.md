# JavaScript Algorithms

A personal project for learning and practicing JavaScript algorithms and computer science fundamentals.

## Goals

- Learn and review fundamental computer science concepts.
- Implement algorithms using JavaScript and TypeScript.
- Visualize how algorithms work.
- Compare algorithms and understand their time and space complexity.

## Sections

- **Concepts:** A collection of fundamental programming and computer science concepts.
- **Algorithms:** Algorithm implementations and visualizations.
- **Compare:** Compare different algorithms based on their performance and complexity.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
